### 矿石与材料

- 银矿石与深板岩银矿石：石镐级，掉落粗银 1 至 2（受时运与精准采集影响），可直接烧炼或高炉成银锭。
- 山铜矿石与深板岩山铜矿石：钻石镐级，双三角分布（峰值约 y=35 与 y=-35），矿石系列方块发光等级 9。
- 秘银矿石与深板岩秘银矿石：钻石镐级，双梯形分布（峰值约 y=25 与 y=-25，每带 count 4、size 8），矿石系列方块发光等级 8。
- 精金矿石与深板岩精金矿石：钻石镐级，双梯形分布（峰值约 y=15 与 y=-15，低概率尾部延伸到 y=60 与 y=-60），矿石系列方块发光等级 8。
- 光辉遗骸（耀金来源）：主世界，发光 12，以 y=0 逐块镜像生成，掉落自身，烧炼或高炉得到耀金碎片（3.5 经验）。
- 英雄躯骸（奥雷利亚尼姆来源）：末地，发光 15，正态分布 y 19 至 60，掉落自身，烧炼或高炉得到奥雷利亚尼姆碎片（4.0 经验）。
- 耀金与奥雷利亚尼姆的碎片、锭、块、碎片堆齐全；下界合金碎片堆由 9 个下界合金碎片合成，也可拆回。

### 装备与模板

- 十二档工具与护甲齐全，属性、耐久与自带附魔按档位递增；耀金与奥雷利亚尼姆通过锻造模板从上一档升级，模板可复制。
- 奥雷利亚尼姆全套四件免疫近战、弹射物与爆炸伤害；时运附魔可用精准采集书在铁砧替换。

## 安装

1. 安装 Minecraft Forge 1.20.1（47.4.10 或更高，运行时范围 [47,)）。
2. 把 jar 放进 .minecraft/mods。
3. 用 Java 17 运行。

可选依赖：JEI（配方查看，含漏斗与机器的说明条目）、Just Enough Resources（矿石分布图）。

## 从源码构建

    ./gradlew build          # 编译、测试、打包
    ./gradlew runClient      # 启动带模组的客户端
    ./gradlew runServer      # 启动专用服务器

产物位于 build/libs/。
