### 配方
**分档升级** —— 每档把同样的五件（熔炉、高炉、烟熏炉、箱子、木桶）从低一档的对应件升级而来：

| 档位 | 升级来源 | 图案 | 成本 |
|------|---------------|---------|------|
| 铜 | 原版对应件 | CCC / CFC / CCC | 8 铜锭 + 原版件 |
| 铁 | 铜 | III / IMI / III | 8 铁锭 + 铜件 |
| 银 | 铁 | III / IMI / III | 8 银锭 + 铁件 |
| 金 | 银 **或** 铁 | III / IMI / III，或 G / GIG / G | 8 金锭 + 银件，或 4 金块 + 铁件 |
| 钻石 | 金 | III / IMI / III | 8 钻石 + 金件 |
| 绿宝石 | 钻石 | III / IMI / III | 8 绿宝石 + 钻石件 |
| 山铜 | 绿宝石 | III / IMI / III | 8 山铜锭 + 绿宝石件 |
| 秘银 | 山铜 | III / IMI / III | 8 秘银锭 + 山铜件 |
| 精金 | 秘银 | III / IMI / III | 8 精金锭 + 秘银件 |
| 下界合金 | 钻石 **或** 精金 | NDN / DPD / NDN，或 N / NPN / N | 4 下界合金锭 + 4 钻石块 + 钻石件，或 4 下界合金锭 + 精金件 |
| 耀金 | 下界合金 | RNR / NPN / RNR | 4 耀金锭 + 对应下界合金件 |
| 奥雷利亚尼姆 | 耀金 | XNX / NPN / XNX | 4 奥雷利亚尼姆锭 + 对应耀金件 |

- III / IMI / III = 该档材料八颗围住低一档的对应件；铜是唯一从原版件起步的档位。
- 金与下界合金是仅有的两个拥有双升级来源的档位；下界合金是唯一使用 4 锭十字而非 8 锭环的档位。
- 跨类型合成一律使用原版材料：5 铁锭 + 该档熔炉 + 3 平滑石 → 高炉；该档熔炉四周 4 原木 → 烟熏炉。
- 下界合金（0.beta.1）：精金工具与护甲配合原版下界合金升级模板，在锻造台上转为原版下界合金对应件（模板消耗，附魔继承）。
- 耀金（0.beta.2）：耀金碎片 x9 ↔ 耀金碎片堆；4 耀金碎片 + 1 山铜锭 + 1 精金锭 + 1 秘银锭 + 1 钻石 + 1 铁锭（无序）→ 2 耀金锭；耀金锭 x9 ↔ 耀金块；耀金升级模板由 4 深板岩 + 4 平滑石 + 1 耀金锭合成，用 1 精金锭 + 7 平滑石复制出 2 个；下界合金装备 + 模板（消耗）+ 耀金锭 → 耀金装备。
- 奥雷利亚尼姆（0.beta.3）：英雄躯骸烧炼或高炉成奥雷利亚尼姆碎片（4.0 经验）；碎片 x9 ↔ 碎片堆；4 碎片 + 1 耀金锭 + 1 精金锭 + 1 秘银锭 + 1 山铜锭 + 1 金锭（无序）→ 3 锭；锭 x9 ↔ 块；升级模板由 4 黑曜石 + 4 末地石 + 1 锭合成（EOE / OAO / EOE），用 1 耀金锭 + 7 末地石复制出 4 个；耀金装备 + 模板（消耗）+ 锭 → 奥雷利亚尼姆装备。
- 下界合金碎片堆（0.beta.4）：9 个下界合金碎片 ↔ 碎片堆（3x3 环，反向无序拆回 9 个）；贴图沿用竹马赛克编织结构。
- 分档潜影盒（0.beta.4）：每条木桶配方把中心木桶换成同档潜影盒，因此盒子像木桶一样逐档链式升级。铜 = 8 铜锭 + 任意原版潜影盒（唯一入口）；铁 = 8 铁锭 + 铜盒；银 = 8 银锭 + 铁盒；金 = 4 金块 + 铁盒 或 8 金锭 + 银盒；钻石 = 8 钻石 + 金盒；绿宝石 = 8 绿宝石 + 钻石盒；山铜 = 8 山铜锭 + 绿宝石盒；秘银 = 8 秘银锭 + 山铜盒；精金 = 8 精金锭 + 秘银盒；下界合金 = 4 下界合金锭 + 精金盒 或 4 下界合金锭 + 4 钻石块 + 钻石盒；耀金 = 4 耀金锭 + 下界合金盒；奥雷利亚尼姆 = 4 奥雷利亚尼姆锭 + 耀金盒。内容物随升级保留。
- 锭 ↔ 粒（9）、块 ↔ 锭（9）、工具／护甲／链按标准图案合成。

### 标签与整合
- Forge 标签：ores、ingots、nuggets、raw_materials、storage_blocks、chests、barrels（通用聚合 + 逐材料；全部 `replace: false`，多模组之间合并而不覆盖）。
- Minecraft 标签：mineable/pickaxe + mineable/axe（箱子与木桶），needs_stone_tool（银矿石），needs_iron_tool（铁至绿宝石档），needs_diamond_tool（山铜、秘银、精金、下界合金、耀金、奥雷利亚尼姆方块）。
- 耀金标签：forge:ores/radiant（光辉遗骸）、forge:ingots/radiant、forge:storage_blocks/radiant + radiant_scrap、forge:chests/barrels；耀金方块全部为钻石级，用镐或斧采集。
- 奥雷利亚尼姆标签：forge:ores/aurelianium（英雄躯骸）、forge:ores_in_ground/end_stone、forge:ingots/aurelianium、forge:storage_blocks/aurelianium + aurelianium_scrap、forge:chests/barrels、forge:armors/*、minecraft:swords/pickaxes/axes/shovels/hoes；奥雷利亚尼姆方块全部为钻石级，用镐或斧采集。
- 所有方块都有战利品表（不写死工具：掉落门控由 requiresCorrectToolForDrops 与 mineable/needs_* 标签决定，其他模组的工具同样可用）；六个模组档位注册进 Forge TierSortingRegistry；所有机器有 JEI 催化剂条目；en_us 与 zh_cn 双语。

### 世界生成（银、山铜、秘银、精金、耀金、奥雷利亚尼姆）
- 特性文件位于 data/mbb_austenium/worldgen；生物群系修改器使用 forge/biome_modifier（单数路径）。
- 银分布：下层 y -24..56（x20），上层 y 80..384（x90），稀有大型矿脉（1/24）。
- 山铜分布：两条三角带（y 5..65，峰值约 35；y -65..-5，峰值约 -35），每带 count 4、size 8；峰值接近原版金矿，衰减更快，尾部稀有延伸至 y=65 与 y=-60。
- 秘银分布：两条梯形带（y 5..45，峰值约 25；y -45..-5，峰值约 -25），每带 count 4、size 8；衰减比山铜更快。
- 精金分布：核心梯形 y 5..25（平台 8，峰值 15）加低概率尾部 y 25..60，负半轴镜像，count 2，size 8。
- 耀金分布：主世界，y 8..24（scattered ore size 3）加均匀带 y 8..64（size 2）；每个放置的方块由自定义特性 mbb_austenium:mirrored_scattered_ore 逐块镜像到 (x, -y, z)，因此分布关于 y=0 完全对称。允许接触空气（discard chance 0），矿脉可以出现在洞穴壁上。
- 奥雷利亚尼姆分布：末地维度（#minecraft:is_end），scattered_ore size 3 与 size 2，discard chance 0（允许接触空气），通过标签 mbb_austenium:aurelianium_replaceables 替换末地石；高度提供器是加权列表高斯近似（y 19 至 60 上 7 条高 6 的均匀带，二项权重 1:6:15:20:15:6:1，均值 y 39.5，sigma 7.54）。
- JER 图表：模组自行写出 world-gen.json 分布点；JER 图表按原始 y 索引，所以点被限制在 y 0..319（负半轴无法在 JER 图表中表示）。
